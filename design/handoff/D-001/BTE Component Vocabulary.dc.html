Component vocabulary

The pieces the meeting report screens are made of, extracted for components/bte/. Every interactive component shows default, hover, focus, active, disabled and loading; every data view shows populated, loading, empty and error. A component with only a default state is not finished.

Both need brand sign-off or a token added by the foundation owner.

components/bte/StatusBadge.tsx

Status badge

2px radius, mono 12px, neutral by default. Semantic colour only when it carries meaning — and the word carries it too, so colour is never alone.

SCHEDULED FILED FILED LATE NOT FILED UNREAD FLAG SHIFT MISSED DRAFT SENDING

A badge is not interactive, so it has no hover, focus or active state — if a status needs to be clickable, it is a button with a badge inside it, not a badge with a click handler. Shift missed is the only ember badge, and it is the one place ember earns its place: ink on an ember fill, one accent, and the word says it too. Only one ember badge may appear on a screen.
