# Campus documents

These are BTE governance documents kept for background. They are not build specifications.

The authoritative specs for this codebase are:

- `docs/DATA_MODEL.md`
- `docs/DESIGN_SYSTEM.md`
- `docs/ARCHITECTURE.md`
- `docs/SLICE_BRIEFS.md`

If a rule in one of these Word files and a rule in those specs disagree, the spec wins. Do not implement from a `.docx` when the spec already states the rule.
